# Security Policy

## Reporting Security Issues

We take the security of this project and any associated services seriously.

If you believe you have discovered a vulnerability, security bug, or sensitive data exposure, please do **NOT** open a public GitHub issue.

Instead, please report it privately:

- **Primary Contact:** [mahdisoleimani2003@gmail.com](mailto:mahdisoleimani2003@gmail.com)
- **Subject Line:** `[SECURITY] 3D Personal Site Vulnerability Report`

Please include in your report:
1. Description of the issue and potential impact
2. Step-by-step instructions or proof-of-concept to reproduce the behavior
3. Relevant versions or environment details

We will acknowledge receipt within 48 hours and work diligently to validate and resolve the vulnerability.
